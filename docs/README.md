# 课程文档

## 交我算 π 2.0 使用教程

- [学生上手教学 PPT](交我算平台Lab运行指南-学生版.pptx)
- [操作讲义与可复制命令](交我算Lab操作讲义.md)

教程覆盖 DataLab、MatrixLab 的源码上传、计算资源申请、编译检查、Slurm 作业提交、
日志查看和结果下载。PPT 中的命令可在配套讲义中复制。

## 与 GitHub 课程仓库配合使用

1. 从教师分配的个人仓库获取课程代码，在本地完成自己的实现。
2. 按教程将源码同步到交我算，在计算节点执行检查和性能实验。
3. 下载日志和实验数据，按各 Lab 题面整理提交材料。
4. 将要求提交的文件推送到个人仓库的 `main` 分支，查看 GitHub Actions 结果。

以教师要求的文件和截止时间为准。交我算上的运行结果不会自动同步回 GitHub。
学生在个人仓库交作业，无需向课程模板仓库提交 Pull Request。
