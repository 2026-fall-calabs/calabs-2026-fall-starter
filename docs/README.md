## 交我算 π 2.0 使用教程

- [学生上手教学 PPT](交我算平台Lab运行指南-学生版.pptx)
- [操作讲义与可复制命令](交我算Lab操作讲义.md)

教程覆盖 SSH `config` 配置、平台免密证书、VS Code Remote-SSH、云盘获取与提交、
源码上传、计算资源申请、编译检查、Slurm 作业提交、日志查看和结果下载。
PPT 中的命令可在配套讲义中复制。

## 课程操作流程

1. 从教师发布的交大云盘链接下载学生框架。
2. 在自己的电脑配置 SSH，用数据节点上传源码；可用 VS Code 连接登录节点编辑。
3. 在 Slurm 分配的计算节点编译并运行实验，保存检查结果和日志。
4. 下载已自测的最终源码，上传当前 Lab 的源码收集任务；报告与日志按通知另交。

以教师要求的文件、提交入口和截止时间为准。云盘上传用于交作业，测试命令仍需
自行执行，教师下载后统一评分。

SSH `config` 和 VS Code 用户设置保存在学生自己的电脑上；使用 Remote-SSH
无需仓库自带 `.vscode/`。GitHub 仓库用于课程材料维护，不承担学生自动测试。
