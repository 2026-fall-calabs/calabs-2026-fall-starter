# 通过交大云盘提交实验作业

## 每个 Lab 提交哪些文件

| 实验 | 源码收集任务上传的文件 |
| --- | --- |
| Lab 1 | bits.c |
| Lab 2 | mygemm.c |

当前两个 Lab 的源码分别上传为单个 .c 文件。报告、实验数据和要求的日志按课程通知
提交到对应入口。后续多文件实验以题目给出的 ZIP 目录结构为准。

## 提交前

1. 保存最终代码，在交我算的计算节点运行该 Lab 的公开测试。
2. Lab 1 在 bits.c 中填写本人姓名和学号。
3. 将远端最终源码下载到自己的电脑，打开检查内容。
4. 确认当前 Lab 的提交入口和截止时间。

在本地终端执行对应的一条下载命令，jiaowosuan-data 的配置见配套讲义：

```bash
mkdir -p pi2-submission
scp jiaowosuan-data:course-labs/labs/lab1-datalab/bits.c ./pi2-submission/
scp jiaowosuan-data:course-labs/lab2-matrix/src/mygemm.c ./pi2-submission/
```

## 上传和更新

1. 打开教师发布的当前 Lab“源码提交”链接，按页面要求登录。
2. 填写学号和姓名。云盘按字段统一命名，例如 0001_示例甲.c。
3. 选择当前 Lab 的源码，点击提交并等待上传完成。
4. 检查自己提交记录中的文件名、大小和时间，保留本地最终版本。
5. 修改后在相同入口重新上传，选择替换旧文件，避免同时保留多个最终版本。

0001 与示例甲仅为演示。请使用本人的学号和姓名。云盘上传完成表示成功交件，
公开测试需要自己运行，正式分数由助教下载源码后统一评测。

课程通知决定最终提交时间和补交规则。不要上传整个课程目录、build、可执行文件、
个人 SSH 配置或密钥。

## 收到反馈后

- 编译失败：检查是否上传了正确源码、语法是否完整、函数接口是否符合题面。
- 正确性失败：查看对应函数和失败输入，在自己的环境中复现。
- 超时或崩溃：检查死循环和数组越界。
- 缺交、重复或身份不符：向助教提供自己的云盘提交记录，核对最终版本。

自动评分只计算正确性，不按运行时间、GFLOP/s 或加速比给分。题目规定的实现方法
与编码限制由助教另行检查。Lab 1 原始满分 50，Lab 2 原始满分 100，课程成绩换算
以教师公布的规则为准。复查时使用助教已归档的源码版本。

参考：[交大云盘文件收集手册](https://pan.sjtu.edu.cn/pandoc/file-collection.html)。
